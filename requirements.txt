# ---------------------------------------------------------------------------
# CuPy (Fat Llama GPU node) is deliberately NOT pinned here.
#
# The correct wheel depends on the CUDA major your torch was built against --
# cupy-cuda12x for CUDA 12, cupy-cuda13x for CUDA 13 -- and pip cannot express
# "match whatever torch is installed". Worse, fat-llama pulls in cupy-cuda12x
# transitively regardless. On a CUDA 13 install that wheel imports successfully
# but dies on the first kernel launch, because CuPy loads nvrtc/cudart lazily:
#     RuntimeError: CuPy failed to load nvrtc64_120_0.dll
#
# Run install.py after installing this file. Its ensure_cupy() reads
# torch.version.cuda, removes the mismatched variant, and installs the right one.
#
# Known tension: deepfilternet declares numpy<2.0, but cupy-cuda13x requires
# numpy>=2.0. No single pin satisfies both. DeepFilterNet works fine on numpy 2.x
# in practice, so the bound above favours CuPy; expect a pip dependency warning.
# ---------------------------------------------------------------------------
